<h1>Проект: Модели, текстуры и др. всех NPC и Монстров из R2 Online</h1>

<p>Этот репозиторий содержит набор файлов моделей, текстур, звуков и эффектов для NPC и монстров для R2 Online. Модели организованы и разделены по папкам в соответствии с ID (MID) монстра или NPC, с последовательностью от меньшего к большему. Всего в репозитории 3423 модели.</p>

<h2>Организация Папок</h2>

<p>В GitHub есть лимит на 1000 файлов в папке, поэтому модели разделены по четырем папкам. Каждая папка содержит 1000 моделей, за исключением последней, которая содержит оставшиеся 423 модели.</p>

<h2>Содержимое Каждой Модели</h2>

<p>Каждая модель включает в себя:</p>

<ul>
	<li>Текстуру NPC / Монстра</li>
	<li>Модель NPC / Монстра</li>
	<li>Звук (если присутствует)</li>
	<li>Эффект (если присутствует)</li>
</ul>
